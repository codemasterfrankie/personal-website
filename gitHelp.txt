COMMANDS TO REMEMBER

- to check what branch you're on:
	git branch

- to switch branches:
	git checkout exampleBranch
	- switches to "exampleBranch"

- to commit changes:
	git commit -a -m 'create thing'
	- -a for all
	- -m for message

- to merge branches:
	git checkout main
	git merge dev
	- go into main, merge dev into main
